# Historias de Usuario

## Backend

- **HU1 (Administrador):** Como administrador, quiero un sistema que me permita crear, leer, actualizar y eliminar (CRUD) publicaciones de blog para poder gestionar el contenido del sitio.
- **HU2 (Administrador):** Como administrador, quiero poder ver la lista de todos los correos electrónicos registrados a través del blog para poder realizar un seguimiento de los suscriptores.
- **HU3 (Sistema):** Como sistema, quiero tener un endpoint de API para guardar de forma segura los correos electrónicos que los usuarios registren en el blog.
- **HU4 (Sistema):** Como sistema, quiero tener endpoints de API para que cualquiera pueda leer la lista de publicaciones del blog y el contenido de una publicación individual.

## Frontend

- **HU5 (Administrador):** Como administrador, quiero una interfaz de usuario con un editor de texto enriquecido para poder crear y dar formato a las publicaciones del blog fácilmente.
- **HU6 (Administrador):** Como administrador, quiero una vista de panel donde pueda ver todas las publicaciones existentes, editarlas o eliminarlas.
- **HU7 (Usuario):** Como usuario, quiero poder ver una lista de todas las publicaciones del blog en una página pública para poder descubrir contenido.
- **HU8 (Usuario):** Como usuario, quiero poder hacer clic en una publicación de la lista y leer su contenido completo sin necesidad de iniciar sesión.
- **HU9 (Usuario):** Como usuario, quiero ver un campo de entrada en las páginas del blog para poder registrar mi correo electrónico y recibir futuras actualizaciones.
